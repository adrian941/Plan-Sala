# Plan Sala & Nutriție — Adi & Ema

Planuri personalizate de antrenament și nutriție pentru Adi și Ema.

## Profiluri

| | Adi | Ema |
|--|-----|-----|
| Înălțime | 192 cm | 185 cm |
| Greutate | 110 kg | 110 kg |
| Distribuție grăsime | Abdominală | Uniformă |
| Scop principal | Masă musculară + slăbit burtă | Slăbit + tonifiere |

## Structura planurilor

```
adi/
├── nutritie.md   → Plan nutriție zilnic (2500 kcal)
└── sala.md       → Split Push/Pull/Legs, 3 zile/săptămână

ema/
├── nutritie.md   → Plan nutriție zilnic (1850 kcal)
└── sala.md       → Split Legs/Pull/Push, 3 zile/săptămână
```

## Principii comune

- **Sală**: 3 zile/săptămână, 1 oră/zi, 2 grupe musculare/zi
- **Progresie**: săptămânile 1-4 greutăți mici (14-16 rep) → 5-8 medii (10-12) → 9+ grele (6-8)
- **Nutriție**: gătit la comun, porții ajustate individual
- **Hidratare**: minim 3L apă/zi fiecare
