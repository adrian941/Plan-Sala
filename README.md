# Plan Sala & Nutriție

Planuri personalizate de antrenament, nutriție și sănătate.

## 📌 Start aici

- **[CLAUDE.md](./CLAUDE.md)** — constituția proiectului (rol, metodă, reguli). Fișier stabil.
- **[Gym-Rules.md](./Gym-Rules.md)** — planul VIU al Emei (sală + nutriție + sănătate), care se updatează iterativ și linkează modular.

## Structură

```
CLAUDE.md        ← reguli stabile
Gym-Rules.md     ← index-master viu (Ema)
ema/             ← modulele planului Emei (profil, nutriție, mese, sală, sănătate, cumpărături, alimente)
```
