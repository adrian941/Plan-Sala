# Plan Sala & Nutriție

Planuri personalizate de antrenament, nutriție și sănătate.

## 📌 Start aici

- **[CLAUDE.md](./CLAUDE.md)** — constituția proiectului (rol, metodă, reguli). Fișier stabil.
- **[Gym-Rules.md](./Gym-Rules.md)** — planul VIU, care se updatează iterativ și linkează modular.
- **[comun/0_pipeline.md](./comun/0_pipeline.md)** — procesul culinar în 3 pași.

## Scop

- **Ema** — plan complet: profil, nutriție, mese, sală, sănătate.
- **Adi** — doar partea de bucătărie (gătesc împreună): preferințe, rețete, ținte de macro/fibre, cumpărături.

## Pipeline culinar

```
1. Ingrediente + preferințe + ținte macro/fibre  →  2. Rețete  →  3. Listă de cumpărături
        (per persoană)                              (comune)         (comună)
```

## Structură

```
CLAUDE.md        ← reguli stabile
Gym-Rules.md     ← index-master viu
comun/           ← pipeline-ul culinar: ingrediente, rețete, cumpărături
ema/             ← profil, nutriție, mese, sală, sănătate
adi/             ← profil, nutriție, mese (doar bucătărie)
```
