# Plan Sală & Nutriție — Ema și Adi

Planuri de mâncare, antrenament și sănătate. **Se gătește și se cumpără la comun**, ținând cont de ce-i place și de ce are nevoie fiecare.

## 📌 Start aici

- **[Gym-Rules.md](./Gym-Rules.md)** — unde suntem, ce e gata și ce urmează.
- **[comun/0_pipeline.md](./comun/0_pipeline.md)** — cum lucrăm la mâncare, în 3 pași.
- **[CLAUDE.md](./CLAUDE.md)** — regulile de fond ale proiectului.

## Cei 3 pași

```
1. Alimente + ce-i place și ce-i trebuie fiecăruia
                    ↓
2. Rețete  →  meniul fiecăruia (aceleași rețete, porții diferite)
                    ↓
3. Lista de cumpărături — una singură, pentru amândoi
```

## Ce unde stă

```
comun/     ← ce ține de mâncare: alimente, rețete, cumpărături
ema/       ← profil, nutriție, preferințe, meniu, sală, sănătate
adi/       ← profil, nutriție, preferințe, meniu   (de completat)
```

Lista de alimente și rețetele sunt aceleași pentru amândoi, de asta stau în `comun/`. Ce diferă de la om la om — nevoile, gusturile, porțiile — stă la fiecare în folderul lui.
